# ADR-0005: 방문·방문자·전환율 정의와 채널 귀속

- 상태: 채택
- 날짜: 2026-09-14

## 맥락
"캠페인별 방문, 방문자, 신청, 전환율" 과 "채널별 성과" 를 보여야 한다. 정의가 요구사항에 없어 가정이 필요하다.

## 결정
- **방문(visits)**: 공개 폼 페이지 응답 1회 = 1건. 200 응답만 기록 (404/403 은 기록 안 함).
- **방문자(visitors)**: 익명 `gu_vid` 쿠키(UUID, 1년, httpOnly) 기준 고유 수. 쿠키 없는 첫 방문에서 발급.
- **신청(submissions)**: 저장된 Submission 행 수. 중복 제출 제한은 두지 않는다 (같은 사람이 여러 번 신청할 수 있고, 운영자가 명단에서 판단).
- **전환율** = 신청 ÷ 방문자. 방문자 0 이면 0. 소수 4자리.
- **채널 귀속**: `/l/{code}` 로 들어온 방문과 그 페이지에서의 제출은 해당 링크의 채널로 귀속. `/f/{slug}` 직접 접근은 채널 없음 → 채널별 성과에서 제외, 캠페인별 성과에는 포함.
- 제출의 `linkCode` 가 다른 폼의 코드면 무시 (오염 방지).
- 링크 삭제 시 방문/신청은 `linkId = null` 로 보존.
- IP 는 salt 해시로만 저장 (원문 저장 안 함).

## 대안
- IP+UA 해시로 방문자 식별: 쿠키 차단 환경에서 동작하지만 NAT 에서 부정확. 필요 시 fallback 으로 추가 가능.
- 채널을 쿼리스트링(`?ch=instagram`) 으로: 사용자가 바꿀 수 있어 데이터 오염. 코드 방식을 택했다.

## 결과
집계는 Postgres 집계 쿼리로 요청 시 계산. 규모가 커지면 일별 롤업 테이블로 전환할 수 있다.
